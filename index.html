Recovery Console

Dua fungsi terpisah: Recovery (jalankan recovery dari file) dan Download to Inbox (unduh file ke GitHub, tanpa recovery).

1. File game (upload dari HP)

Belum ada file dipilih.

2. Atau link download (tanpa upload)

Runner yang download sendiri, HP tidak perlu download game aslinya. Wajib link langsung (bukan halaman web, bukan Google Drive).

3. Aksi (mode upload)

Upload lama = file yang sudah ada di inbox repo gdsdecomp (mis. CGOW.apk 18 bagian). Pilih file yang sama di section 1 (untuk nama), lalu tekan tombol ini.

4. Recovery dari inbox repo ini

Untuk file yang sebelumnya disimpan lewat tab Download to Inbox (utuh atau berbagian, terdeteksi otomatis). Key enkripsi diambil dari section 1.

5. Status recovery

Menunggu. Upload file dulu, lalu jalankan recovery.

6. Hasil

Link download muncul di sini setelah recovery hijau.

Download ke inbox GitHub

GitHub Actions yang mengunduh, HP tidak ikut mengunduh. File disimpan ke branch pck-inbox tanpa menjalankan recovery. Harus direct download http/https (bukan halaman web, bukan Google Drive); situs yang butuh login atau cookie tidak didukung.

Ekstensi pck, exe, apk, atau zip. File sampai 90 MiB disimpan utuh; lebih besar dipecah 20 MiB (nama.part001, ...). Maksimal sekitar 3500 MiB.

Status download

Menunggu. Masukkan URL lalu tekan Download to Inbox.
